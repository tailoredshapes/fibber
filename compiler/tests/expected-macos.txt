# compiler/tests/expected-macos.txt: what `gmake mac-check` (mk/mac.mk) does NOT run on macOS, and why. One line each:
#   tool  NAME  reason      a tool test of mk/tools.mk (build/tools/NAME.ok)
#   stage NAME  reason      a stage of the gate (static, wasm)
#   golden NAME reason      a golden suite of compiler/tests/golden/suites.sh (build/golden/NAME.ok)
# A tool listed here is skipped on a Mac and runs everywhere else; the reason is a fact about the tool or the machine, checked when it was written.
# A tool that fails on the Mac for a reason nobody has found is NOT listed: it fails the check until fixed or understood. Lines starting with # are comments.
# (Cases that fail on the Mac only are scripts/ci-stage2.expected-darwin; the Linux-only lines of the scripts carry `# linux-only: reason`, scripts/lint-portable.sh.)
tool sh-driver-cpu-check   plants x86-64-v4 and reads /proc/cpuinfo: a test of the x86-64 start-up CPU check; the Mac is arm64
tool sh-driver-muladd      builds and runs x86-64-v2/v3 programs and reads nm -D (ELF) output; the Mac is arm64
tool sh-driver-no-fma      builds and runs x86-64-v3 programs and reads /proc/cpuinfo; the Mac is arm64
tool sh-lanes-lanes        builds and runs x86-64-v3/v4 (AVX2, AVX-512) lane programs and counts zmm instructions with objdump; LLVM does not know those CPUs for arm64 (the aarch64 lanes are docs/design/aarch64.md and scripts/shootout/a64-bench.sh)
tool js-backend            two of its lIR cases are glibc/x86 text (cases/lir/instr/declare-global.lir declares @stderr, which macOS spells __stderrp; cases/lir/simd/target.lir needs +sse4.2); the other 8121 checks pass on the Mac, but the tool compares against one expected list (compiler/tests/js/expected.txt)
golden emit-defs           the golden is the lIR/LLVM text of the x86-64 host (FIB_TARGET_CPU=x86-64-v2, an x86 triple); on arm64 LLVM warns that x86-64-v2 is no CPU for the target and the text differs
golden emit-fns            the same: the golden records x86-64 host output
golden lair-llvm           the same: the golden records x86-64 LLVM IR
