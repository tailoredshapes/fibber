Also changed, for the porters' tests of the interpreter and the runtime (not the expander):
the builtin Show of a non-finite float is `##Inf`, `##-Inf`, `##NaN` (`crates/fibref/src/eval/floattext.rs`
`float_text`, `crates/fibc/rt/str.lir` `fib.show-fp`); `ToStr` of a float keeps Java's `Infinity`

Cases 2973, 2974.

Mirror notes for the porters. (1) `some`'s `Declined` path leaves the call for the constructor, the
same `Outcome` the binary `+` uses. (2) The `for`/`doseq` rows use no state beyond the gensym
counter: the order of gensym creation (`s` of the outer `:when` guard, `err` innermost first in
`try-let`, `c` before `n` in `vswap!`, `k` for `max-key`) is what the dump tests print as
`#s.1`, `#err.1`, `#c.1 #n.2`, `#k.1`. (3) `fib.coll/conj` and `fib.seq/..` heads are the facades'
qualified names (spec §6.2); a module that does not have the facade in scope cannot expand a call
of these macros, as `fib.core/to-str` of `str`.
