# S5: the sys builtins (fd primitives)

Spec: stdlib §4.19, syntax §4.3 (the row "the unix primitives"). Cases: `cases/stdlib/3600` to `3609`.

Sixteen builtins, `sys-open sys-close sys-read sys-write sys-seek sys-pipe sys-dup sys-isatty sys-unlink sys-mkdir
sys-rmdir sys-errno-text sys-getenv sys-clock-now sys-wall-now sys-sleep`, are in
the Rust front end and runtime. The fibber ports must learn them, or stage 2 cannot read `lib/fib/unix.fib`
(it uses them) nor emit a program that does.

| Rust | What | Port that must change |
|---|---|---|
| `crates/fibref/src/types/builtins.rs` `BUILTINS` (sixteen `b("sys-..")` rows, between `write-file` and `str-concat`) | the signatures and escape modes: `sys-write` borrows its `(Array i8)` (`B`), `sys-open sys-unlink sys-mkdir sys-rmdir sys-getenv` borrow their `str`, the rest take scalars | `compiler/types/builtins.fib` (the table), and `compiler/own/` if it has its own escape table |
| `crates/fibref/src/eval/sys.rs` `Interp::sys_builtin` | the semantics (the reference) | nothing: stage 2 has no interpreter |
| `crates/fibc/src/lower/sys.rs` `Cx::sys_builtin` (called from `lower/builtins.rs` `builtin`, arm `n if n.starts_with("sys-")`) | each builtin is a call of `fib.sys-NAME` in the runtime, returning `i64` (`i1` for `sys-isatty`, `ptr` for `sys-errno-text`, `sys-getenv`); `sys-read` takes one more argument, the type id of `(Array i8)` (as `str-bytes` does), and answers `ptr` | `compiler/emit/lower/builtins.fib` (the same dispatch) |
| `crates/fibc/rt/sys.lir`, new, listed last in `compile.rs` `RUNTIME` | the runtime functions and the C declarations (`openat read close lseek pipe dup isatty unlink mkdir rmdir strerror clock_gettime nanosleep __errno_location`) | DONE here: `compiler/emit/runtime.fib` is regenerated (`RT-SYS`), `compiler/emit/rt.fib`, `gen-runtime.fib` and `unit-runtime.fib` list the eleventh part; `compiler/tests/emit/runtime.sh` passes |

Until the first three rows are mirrored `F emit compiler/fibc.fib` and `fibc emit compiler/fibc.fib` differ
(the runtime text now has `sys.lir`; the lowering does not know the builtins). The library module is
`lib/fib/unix.fib`, which `:use`s nothing special.
