## Finding the porters need

`fibc emit` is not deterministic for a program whose `async` frame keeps several values live across an
`await`: `crates/fibc/src/resume.rs` takes the live names from a `HashSet` and assigns frame slots (and
`edge_loads`, a `HashMap`, is iterated) in hash order. `cases/ownership/174-awaits-in-a-loop-with-live-locals.fib`
printed nine different texts in ten runs of the unchanged `fibc`. Until the Rust sorts them (names by first
definition), `bootstrap_emit` cannot judge those files byte for byte. Not changed here: it is the lowering.
