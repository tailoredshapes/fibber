# X8: what the stage-2 checker and emitter must reproduce (mirror pending, L15)

Mirror duty is suspended (owner, 2026-10-02): nothing under `compiler/expand/` or `compiler/types/`
is edited. X8 changes **no expander and no prelude**. It changes the type checker (the `def` rule)
and the interpreter and `fibc` (how a `def` is made), which are not mirrored in fibber yet.

## Expander (`compiler/expand/**`)

Nothing. `def` reaches the checker as before; the grammar of `def` forms is unchanged.

Decisions where the spec was silent: a `def` may read a **later** `def` of its module directly or
through a function (the dependency order evaluates the later one first; a cycle is the existing
`DefCycle`); a macro-time module does not make run-time `def`s (a macro that reads one is
`unsupported`); `fibc` cannot yet make a run-time `def` of a `dyn` type (`unsupported`).
